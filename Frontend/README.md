# 🍦 Sweet Freeze

Sweet Freeze es una página web enfocada en los amantes de los helados. El sistema permite visualizar diferentes tipos de helados, personalizar combinaciones y crear tu propio helado según tus gustos. Además, cuenta con un sistema de inicio de sesión para los usuarios.

---

## 🚀 Características

- Inicio de sesión de usuarios.
- Visualización de diferentes tipos de helados.
- Área de personalización de helados.
- Interfaz amigable y moderna.
- Gestión de datos mediante base de datos MySQL.

---

## 📸 Funcionalidades principales

### 🔐 Inicio de sesión
El sistema cuenta con autenticación de usuarios para acceder a las funciones disponibles.

### 🍨 Personalización de helados
Los usuarios pueden seleccionar diferentes ingredientes, sabores y opciones para crear su propio helado personalizado.

### 🧾 Gestión de información
La aplicación maneja datos de clientes, productos, pedidos, empleados y facturación utilizando MySQL.
